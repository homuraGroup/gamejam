## 状态说明

- `待确认`：已存在于工程，但缺少负责人或语义还需要人工确认。
- `待使用`：预留但还没落地。
- `使用中`：已经在地图、公共事件、数据库、插件配置或资源引用中出现。
- `废弃`：不再使用，但暂不删除，避免旧事件引用。
- `待迁移`：准备替换 ID 或资源路径。

## 维护规则

- 新增开关或变量时，优先使用 `System.json` 中没有名字、且本表没有使用记录的 ID。
- 修改 `(未命名)` 但 `使用中` 的开关前，先确认关联地图的事件含义，再补名字。
- 公共事件 1-4 当前是空壳。启用前必须补名称、用途、负责人和触发范围。
- 新增资源只登记项目自定义资源，不登记 RPG Maker 默认素材。
